# 自动化填写功能增强计划

## 问题分析

当前用户的工作流程：

1. 在 TABuddy 中为每个学生生成课后反馈
2. 手动复制每个学生的反馈内容
3. 打开混合学习中心网站 (<https://il.xdf.cn/plus/calendar>)
4. 找到对应学生的输入位置，手动粘贴

这种操作非常繁琐，需要跨页面反复切换。因为**跨域安全限制**（CORS/同源策略），我们的 Web 应用无法直接操作混合学习中心网站的 DOM。所以需要通过**控制台脚本注入**的方式实现自动填写。

## 设计思路

### 核心架构

```
TABuddy App（生成反馈）
       │
       ▼ 点击"自动填写"
       │
  收集所有学生反馈数据
       │
       ▼
  生成增强型自动填写脚本
  ├── 包含所有学生的反馈数据
  ├── 在目标页面注入浮动工具栏
  └── 支持学生选择和一键填写
       │
       ▼ 用户复制脚本
       │
  打开混合学习中心
       │
       ▼ 粘贴脚本到控制台
       │
  浮动工具栏出现 → 选择学生 → 自动填入对应位置
```

### 改造范围

改造现有 `AutoFillConfigPanel` 组件，并添加新的集成组件和功能。

***

## 实施步骤

### Step 1: 重构 AutoFillConfigPanel → AutoFillWizard（自动填写向导）

**目标：** 将现有的简单配置面板升级为完整的向导式体验

**文件：** `components/feedback/AutoFillWizard.tsx`（新建）

**功能要点：**

#### 1.1 数据准备功能

* 在向导中新增"反馈数据"选项卡，显示当前班级所有学生的反馈列表

* 从父页面接收学生的反馈数据（通过 props 或回调函数）

* 支持搜索/筛选学生

* 预览每条反馈内容

#### 1.2 增强型脚本生成

生成的脚本不再只是简单的表单填充，而是包含：

* 所有学生的完整反馈数据（嵌入脚本中）

* 在目标页面注入一个**浮动工具栏**（固定在页面右下角）：

  * 学生下拉选择器（可搜索）

  * 反馈内容预览面板

  * "一键填写"按钮

  * "上一学生/下一学生"导航

  * 批量模式：遍历所有学生

#### 1.3 配置管理增强

* 保留原有的 URL + CSS 选择器配置

* 增加**预设系统**：

  * 内置"混合学习中心"预设（通用选择器模板）

  * 支持导出/导入配置（JSON）

* 添加**配置测试**功能：生成测试脚本来验证选择器是否匹配

#### 1.4 步骤式向导界面

* Step 1: 选择/配置目标网站

* Step 2: 确认反馈数据

* Step 3: 生成并复制脚本

* Step 4: 操作指引（如何打开控制台执行）

***

### Step 2: 在反馈管理页面集成增强版自动填写

**目标：** 替换 feedback/page.tsx 中现有的 AutoFillConfigPanel，使用新的 AutoFillWizard

**文件：** `app/(app)/feedback/page.tsx`

**修改要点：**

* 将 `AutoFillConfigPanel` 的引用替换为 `AutoFillWizard`

* 在打开自动填写面板时，将当前班级所有学生的反馈数据传递给 AutoFillWizard

* 保留原有的"自动填写配置"按钮

***

### Step 3: 在作业管理页面添加自动填写入口

**目标：** 作业管理页面也能使用自动填写功能

**文件：** `app/(app)/homework/page.tsx`

**修改要点：**

* 在作业管理页面顶部工具栏，添加"自动填写反馈"按钮

* 点击后收集当前班级所有学生的**最新作业评估反馈**（`feedback` 字段）

* 打开 AutoFillWizard 面板，传入学生的作业反馈数据

***

### Step 4: 内置混合学习中心预设配置

**目标：** 开箱即用，用户无需手动配置选择器即可使用

**文件：** `components/feedback/autoFillPresets.ts`（新建）

**功能要点：**

* 定义一个预设数据文件，包含混合学习中心网站的常用选择器

* 预设内容：

  ```typescript
  {
    name: '混合学习中心',
    url: 'https://il.xdf.cn/plus/calendar',
    selectors: [
      // 通用的常见教育平台选择器模式
      // 用户可根据实际页面结构调整
    ]
  }
  ```

* 提供"一键导入预设"功能

* 允许用户在预设基础上修改

***

### Step 5: 脚本生成引擎升级

**目标：** 生成更智能、更易用的自动填写脚本

**文件：** `lib/auto-fill-script-generator.ts`（新建）

**功能要点：**

* 接受参数：学生反馈数据数组、CSS 选择器配置、目标 URL

* 生成的脚本包含：

  1. **数据层**：所有学生的反馈数据
  2. **UI 层**：浮动工具栏的 HTML/CSS/JS（全部内联）
  3. **填充逻辑**：根据选择器找到表单元素并赋值
  4. **事件通知**：填充后触发 input/change 事件以确保框架（如 Vue/React）捕获到值变化
  5. **错误处理**：选择器不匹配时的友好提示

* 脚本格式同时适用于**控制台粘贴**和**书签工具（bookmarklet）**

***

### Step 6: 完善用户体验细节

* 复制脚本时 toast 提示"脚本已复制，请打开目标网站按 F12 粘贴执行"

* 提供简短的操作视频/动画指引

* 浮动工具栏 UI 风格与混合学习中心融合（简洁、不突兀）

* 支持键盘快捷键（Ctrl+Enter 填充当前学生）

## 技术约束说明

1. **跨域限制无法突破**：由于浏览器安全策略，无法从 TABuddy 直接控制混合学习中心的页面。控制台脚本注入是目前最实用的方案。
2. **选择器配置依赖用户**：混合学习中心的 DOM 结构可能变化，需要用户根据实际页面调整 CSS 选择器。
3. **浮动工具栏增强体验**：在目标页面注入 UI 面板，让用户不需要反复切换页面即可完成所有学生的填写。
4. **触发框架事件**：生成的脚本会触发 `input` 和 `change` 事件，确保 Vue/React 等现代框架能感知到值的变更。
